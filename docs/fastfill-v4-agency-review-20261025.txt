三、优先研究方向（均为假设）
1. Calibrated geometric/support risk for commitment and retraction
实验：Freeze one checkpoint. Use 100-300 validation rooms for a pilot, with a final untouched grouped test set. Compare random ordering, current maximum XY probability, deterministic geometry margin and a calibrated joint-risk policy under the same 1/2/4/8-round budgets. Report attachment-only separately.
指标：All-request geometric pass/violation/unknown counts, reference errors where labels are valid, decoding calls, prefill/decoder/raster/validator latency and p95 end-to-end latency. Fit any calibration only on held-out validation partitions, not test outcomes.
判败：A learned policy fails to outperform a simple geometric ordering at equal compute, or gains disappear when attachment and legality rules are held equal.
原型估时：1-3 engineer days for a frozen-checkpoint pilot after correctness fixes; full training cost depends on actual hardware.

2. Local repair after asset substitution
实验：In 50-100 validation scenes, replace one asset with another catalog asset whose immutable native size differs. Reopen only that asset, necessary support descendants and conflicting neighbors; compare bounded translation, full-scene decoding and local masked repair. A synthetic dimension-perturbation stress test is a separate preliminary stage, not evidence of real mesh correctness.
指标：All requested IDs retained, unchanged native asset scale, zero locked-object drift, support/contact evidence status, collision/boundary violations, number of moved objects and latency. Use verified support surfaces or explicitly report unknown support.
判败：An apparent gain comes from dropping objects, resizing assets, moving locked background, hiding unknown checks or using more compute than the comparison.
原型估时：3-5 engineer days for a bbox/verified-surface prototype; mesh or physics integration is a separate task.

3. Counterfactual control over support dependencies
实验：Extend the existing code_v4 v1 contrast_set concept into structured v2. Generate pairs with the same room/inventory but two different feasible constraints, each with an independent witness. Include support descendants and fixed obstacles; compare compliance, preservation and runtime under both constraints. Use natural-language graph-edit and rule-based baselines under matched inputs.
指标：Paired constraint-response success, retention of unaffected geometry, support-closure consistency and group-clustered confidence intervals; semantic-facing claims use only verified front evidence.
判败：The model imitates the original reference but does not respond to the alternate feasible condition, or success relies entirely on deterministic postprocessing.
原型估时：2-4 engineer days for a bounded validation set and evaluation harness; these estimates exclude model retraining.
