**已确认的几何转换问题：区分成品与中间 IR。**

1. **Scan2CAD：超过 10° 倾斜时，局部尺寸被直接用作仅含 yaw 的直立框。** `scan2cad.py:74–80` 用未旋转的局部高度计算底面；`unified.py` 仅保留 yaw 和交换后的局部尺寸。两物体独立原始 TRS 对照、最终八物体逐一按导出原 R/size 枚举角点，证明这些源导出没有预先包络，不能把缺失的 roll/pitch 当成已处理。全量 1,506 个 scan 的源 scale 都严格为 `[1,1,1]`，排除了 exporter 漏除 scan scale 的怀疑。当前 IR 有 640 个大倾斜对象；对实际成品逐行关联并用当前 prep/augmentation 重放，确认成品 train 中实际受影响为 **6 房 / 8 目标**，默认 flag 过滤后 **5 房 / 7 目标**。八个对象重算后即使厘米量化尺寸也都改变，最大轴差 9.39–19.93 cm。例：`Scan2CAD::scene0043_00`，train 第 50706 行；椅子旧框约 `0.529×0.610×0.985 m`，同 yaw 角点包络约 `0.721×0.698×1.120 m`。两例修正底面经原有 15 cm 贴地规则仍为 0，不能声称它们最终 z 必然改变。≤10° 的既定去噪策略不算本项错误。

2. **IL3D_3dfront：斜墙窗的世界轴投影宽度被误作沿墙宽度。** 上游 README 和 exporter 明确 `width=max(X跨度,Y跨度)`；`il3d_3dfront.py:203–223` 从 profile 取斜方向后仍把该标量用于沿墙局部尺寸。独立源 house mesh 顶点、导出 profile、当前 adapter、冻结 IR 和保存的整组 fixed 输入均核对成立。严格只计普通三维竖直矩形窗，确认 **39 个窗 / 24 个保存房间**，其中 **25 个窗 / 15 个默认训练保留房间**。例：train 第 1884 行，`il3d:b57d891e-86d4-11f0-a478-60cf84ae2082` 的 `window_4`，真实沿墙宽 `0.42090387 m`，IR `0.3623 m`，保存输入 `0.36 m`，flags 为 `{}`。这是 **fixed 条件输入**错误，不是窗户 placement target 标签错误。探索中的 66 个门候选、不规则 bay window 没有算入确定影响数量。

3. **SpatialGen：完整倾斜 transform 被仅含 yaw 的框替代。** `spatialgen.py:16` 直接调用只含 yaw 的统一转换，没有重算倾斜八角点包络，也没有声明近似角度阈值。全源 8 个倾斜对象中，6 个被后续 scope 过滤，**2 个保留为 test 中的 painting_1 待摆对象**：scene_00024 和 scene_00030。前者 IR 薄轴 0.04 m，同 yaw 源包络约 0.142731 m；后者 0.03 m 对应约 0.159781 m。后者已独立读取原始 room_layout.json，直接乘原始 4×4 transform 的八角点复核（无 mirror、约 10° 倾斜），并与 test 第 5423 行完整对象输入和 placement 重放相等。它们存在于保存 user objects 和 assistant placements，不是 fixed。该源仅用于测试，不影响训练行。不要把 8 个 IR 对象全部当成最终 test 错误，也不要将两例推断为全部 45 个测试房间无效。

4. **SceneSmith：墙挂资产原点并非全部为竖直中心。** 3,011 个墙挂对象中有 46 个对应资产 local AABB 的 z 范围为 [0,H]；`scenesmith.py:50` 仍统一减 H/2，导致中位约 35 cm、最大约 1 m 的中间 IR 垂直偏移。**46 个都没有保留为当前 test 的 target 或 fixed**，这 31 房当前仍能通过 prep；不能称当前 364 条 SceneSmith 消息的可见对象全被污染。尚未排除它们经支撑推断、对象过滤或 flags 间接影响其他保留内容；target/fixed 都为 0 不等于间接影响为 0。其余轴/原点合同和全量 current→frozen 重放见逐源证据。

**需要更正的旧结论：几何替代轴不能直接当作语义错误标签。**

InternScenes 的本地导出 README 与 exporter 定义了 bbox 局部轴及 ZXY 角，但未找到“每个资产 local +X 都是语义正面”的逐资产保证。`inspect_ir` 靠墙统计只是启发式，且其类别集合不包括之前的 TV/monitor 两例。当前 `upright/tilted_bbox` 的几何换轴有明确用途，独立 1,000 个随机框（含 500 个反射/重排正交基）的包络误差小于 `1.78e-15 m`。本轮不再将 `k=0` 一律定性为确定错误，也不建议直接批量补 `front_known=False`。

全量源统计有 20,747 个 k=0 对象；与实际保存 UID 关联并完整重放 6,389 房后，成品 train 保留其中 9,030 个目标，默认 flag 后为 **5,874 个目标 / 2,927 房**。这些是**替代轴暴露数量，不是错误数量**。保存的 train faces 关系仅 1 条由 k=0 对象作主语；dev/test constrained sidecar 各 1 条。旧 TV/monitor 两例有 yaw 监督，但没有作保存 train faces 的主语。

直接设 `front_known=False` 的两房反事实会删除目标，并可能新生 fixed_collision，使整行被默认训练排除；不是无副作用元数据修补。MansionWorld/SAGE 的前轴也应区分项目约定、经验推断和源官方真值；MultiScan “front 总沿 box 轴、up 总是 axis1”的注释也有实际例外。本轮保留语义不确定性，不制造新的水平语义朝向。

**中间 IR 的已证问题与当前成品未测到的缺陷。**

- InteriorGS 的 2 cm 快捷分支可误处理薄型侧放灯具；已复现近零宽与不稳定 yaw。所核三盏 Linear lamp 都被 build 排除，既不是 target 也不是 fixed，不能称当前训练污染。
- SceneSmith 墙挂资产原点问题的实际影响在上方逐源结果中分层记录；不能以 IR 有误推断保存消息必有误。
- build 在厘米/整数角量化前检查支撑，量化后可能把源 5 cm 容差变成 5.5 cm 而仍成功。独立完整扫描当前成品 **160,964 行、1,990,430 物体、596,301 支撑边**，各 split 均 0 支撑/落地高度失败。因此是未来边界风险，不是要求重建现有数据的独立理由。
- dedup 先淘汰源再 split，可在未来输入丢失落败源 eval_only/alias；当前 18 个冻结 IR 的 188,670 行元数据全扫有 715 个跨源 group，其中没有携带这些限制信息的组，未证实现有泄漏。所有非空边界最小 XY 为 0，也满足当前旋转去重的原点前提。

**验证记录。**

先前同一代码哈希的标准 suite 为 **138 tests + 90 subtests 全通过**，14 个 adapter 自检通过；整体 production 行覆盖率 **2602/4163=62.5%**，不是 80% 或 90.8%。本轮另执行 adapter 46 tests、core 79 tests + 90 subtests，均通过；它们与标准 suite 有重叠，不能相加成独立测试总量。训练方面复用同哈希的真实 Qwen tokenizer 与 6,592 参数 tiny Qwen3 CPU 一步 LoRA/评估/保存验证，没有重跑 8B 或 GPU/DDP。测试绿色不等于源转换正确，新发现正说明需补真实源回归。

没有完成每个 mesh 的物理/语义真值检查，没有全量重新推导每个房屋 floor mesh、全量重标语义正面、GPU/vLLM 真实服务、模型质量 benchmark，也没有运行依赖漏洞数据库审计。22 项中有 6 个原始目录缺失，其中 3 个有注册 adapter，均不能标为源数据审核通过。每源报告对全量字段/数值/重放与抽样角点/mesh 对照分别列明。
