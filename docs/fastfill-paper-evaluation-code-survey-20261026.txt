一、直接采用的结论

1. baseline优先试MiDiffusion object_conditioned：固定类别/数量而继续预测尺寸和pose；需要把benchmark数据入口换成同一份用户清单。
2. ReSpace适合作为文字＋真实mesh对照；固定清单、修正失败记0，并统一候选选择预算之后再比。
3. SceneEval可提供主要几何与可用性模块；同时用request ID确定性检查完整清单，并加从入口出发、按实际agent宽度的可达检查。
4. 借鉴LEGO-Eval的逐要求满足率与全部要求同时满足率；VLM评委本身需小规模人工校准。FID/CKL/单GT pose误差是辅助。
5. RoomGenBench负责最终真实mesh层：既看资产描述和coverage，也重测碰撞/越界/接触/门窗。NaLA、OptiScene原生已知asset/尺寸的条件需单独标注。

二、快速对照（每组最多4项；所有GitHub链接均在后文逐项列出）

Classic generative layouts

  DiffuScene：FID/KID/SCA/CKL；bbox交叠与对称统计。代码：已核FID/KID/PR及AABB统计；未找到独立SCA/CKL入口。
  MiDiffusion：FID/KID/KL/分类CA；OOB、bbox IoU。代码：模型库＋官方ThreedFront评估库。
  InstructScene：iRecall；FID/CLIP-FID/KID/SCA。代码：已核关系、图像指标脚本；SCA聚合需审查。

LLM scene/layout methods
  LayoutGPT：矩形房间OOB、类别KL、渲染FID。代码：已核OOB/KL＋vendored ATISS FID。
  Holodeck：人工偏好、场景CLIP、下游ObjectNav SR/SPL。代码：公开生成/检索/渲染；当前树未找到论文完整评分器。
  OptiScene：FID、OOR、GPT评分、UR人评、编辑/导航。代码：公开SFT/DPO/merge/inference；当前树未找到评分器。
  ReSpace：mesh体素OOB/碰撞VBL；FID/CLIP-FID/KID；PMS；人评。代码：已核src/eval.py和full/instr脚本；未找到完整人评分析。

Recent generation systems
  SceneNAT：iRecall、FID/CLIP-FID/KID、DOS、交叠和时间。代码：已核入口及部分指标；当前IoMin实现有归一化反例。
  NaLA：加权voxel碰撞、加权OOB、floating、AI/人评。代码：有train/infer；当前树未找到论文评分器。
  SceneSmith：要求满足、COL/OOB/NAV/ACC；Drake稳定性；人评。代码：主库导出/任务验证；作者SceneEval fork有自动评估。

Evaluation/architecture/downstream frameworks
  SceneEval：数量/属性/关系满足＋碰撞/支撑/导航/可达/OOB/开口。代码：已核实际metric模块和无VLM运行计划。
  LEGO-Eval：逐约束Partial SR、全部约束Holistic SR；人类一致性。代码：已核21工具框架、入口与成功率聚合。
  SemLayoutDiff：FID/KID/SCA/CKL、中心点OOB；SceneEval补充。代码：已核统一eval入口和4类metric模块。
  RoomGenBench：资产VQA/SigLIP/R@5、coverage、支撑；参考mesh诊断。代码：已核render/geom/VLM/aggregate。

四、不能直接混到同一列的指标

1. “碰撞”：DiffuScene默认AABB全pair统计、MiDiffusion的bbox IoU、SceneEval mesh参与碰撞对象率、NaLA体积加权pair指示、ReSpace体素交体积，各自分子/分母/几何不同。保留原口径，并另跑统一evaluator。
2. “越界”：SemLayoutDiff中心点、LayoutGPT矩形+10cm容差、MiDiffusion旋转bbox收缩容差、SceneEval mesh射线、NaLA体积加权越界面积，不能只写OOB后合榜。
3. “分类准确率”：不同SCA/CA代码有持续训练、最优batch、独立重置、低于50%翻转等不同协议；不是家具类别正确率。
4. “遵循指令”：iRecall通常是要求的类别关系triplets，PMS是描述词命中，LEGO是逐约束判定；都不能自动替代完整request ID/类别/数量检查。
5. “成功/耗时”：单物件平均通过不能替代整房间全要求通过；batch生成时间不能替代batch=1完整流程延迟。多候选筛选、repair、检索、资产生成与失败均需记录。
