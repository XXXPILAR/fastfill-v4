# FastFill v3.2 code snapshot

See [fastfill/README.md](fastfill/README.md) and [release notes](fastfill/RELEASE_v3.2.md). Install the CUDA-compatible PyTorch build for your server, then `pip install -r fastfill/requirements.txt`. Run `python -m pytest -q -p no:cacheprovider fastfill/tests` after installing pytest.

This versioned directory does not replace the code used by existing v3/v3.1 runs.
